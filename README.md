# 🔒PassGen

  Надежный и быстрый генератор паролей на языке C, работающий из командной строки.

## ✨Особенности
  
- **Безопасный парсинг аргументов:** Используется `strtoull` с полной валидацией ввода (защита от переполнения, отрицательных чисел и нечисловых символов).
- **Защита от смещения по модулю (Modulo Bias):** Алгоритм отбрасывает значения из "хвоста" распределения, гарантируя, что каждый символ из набора имеет абсолютно равную вероятность выпадения.
- **Платформонезависимость:** Использование типов из `<stdint.h>` и `<inttypes.h>` гарантирует корректную работу как на 32-битных, так и на 64-битных системах (Linux, Windows, macOS).
- **Пакетная генерация:** Возможность сгенерировать несколько паролей разной длины за один запуск программы.

  ## 🛠Сборка

* Для компиляции требуется любой современный компилятор C (GCC, Clang). Рекомендуется использовать строгие флаги предупреждений:

```bash
gcc -Wall -Wextra -Wpedantic -O2 -o passgen main.c
```

* Или просто:
```bash
gcc -o passgen main.c
```

## ⚙️Использование

### Генерация пароля по умолчанию (16 символов)

```bash
./passgen
```

### Генерация пароля заданной длины

```bash
./passgen 32
```

### Генерация нескольких паролей за раз

Можно передать несколько аргументов, и программа выдаст пароль для каждого из них:
```bash
./passgen 8 16 32
```

### Обработка ошибок

Программа строго валидирует ввод и завершится с кодом ошибки `1` при некорректных данных:

```bash
$ ./passgen -5
ERROR: аргумент '-5' не может быть отрицательным

$ ./passgen abc
Ошибка: 'abc' не является корректной длиной (допустимо 1-255)
```
## Технические детали

- **Максимальная длина пароля:** 255 символов (защита от переполнения стека).
- **Набор символов:** Строчные и прописные буквы латинского алфавита, цифры и специальные символы (`!@#$%^&*()-+[]{}?`).
- **Генератор:** Линейный конгруэнтный генератор (LCG) с параметрами MINSTD (a=16807, m=2^31-1), инициализируемый системным временем.
